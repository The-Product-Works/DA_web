# Olist Data Analytics Pipeline - dependencies
#
# This project has NO Python or npm source code: it is n8n workflow JSON (n8n/),
# PostgreSQL SQL (setup/sql/) and Metabase config (setup/metabase/).
# So there is nothing to `pip install -r` from this file. It is a manifest of the
# external software and services the pipeline needs, with the minimum
# versions required. Installation, configuration and cloud/local setup steps are
# in SETUP.md.
#
# Lines starting with "#" are informational. Do not run pip against this file.

# --- Runtime software -------------------------------------------------------
# n8n            >= 2.42.7 (minimum version)
#                  Local : Docker (recommended) OR Node.js + npm  ->  npm install -g n8n   (version 2.42.7 or newer)
#                  Cloud : n8n Cloud, or self-hosted n8n on a server (see SETUP.md)
# Node.js        only if you install n8n with npm; use a version supported by your chosen n8n release
# Docker         optional but recommended: runs n8n and Metabase locally (Docker Desktop or Engine + Compose plugin)
# PostgreSQL     >= 15 (minimum version; Supabase PostgreSQL is the documented target)
# Metabase       self-hosted, via setup/metabase/docker-compose.yml (image metabase/metabase:latest; pin a tag for production)

# --- Data -----------------------------------------------------------------
# Olist Brazilian E-Commerce dataset (not bundled): https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

# --- Hosted services / accounts ---------------------------------------------
# Supabase                project with PostgreSQL access and room for ~1M geolocation rows plus clean/analytics copies
# Google account          Google Drive + Google Sheets (source CSVs, spreadsheet, mock-API JSON files)
# Google Cloud project    Drive API + Sheets API enabled (required for self-hosted n8n OAuth; not needed on n8n Cloud)
# Anthropic API key       Collection workflow   (model: claude-sonnet-5-5)
# Google Gemini API key   Cleaning, Transformation, Explain workflows   (model: models/gemini-2.5-flash)

# --- n8n node families used by n8n/*.json (built into n8n, nothing to install) -
# n8n-nodes-base: code, postgres, googleDrive, googleSheets, httpRequest, webhook, respondToWebhook,
#                 extractFromFile, executeWorkflow, executeWorkflowTrigger, splitInBatches, splitOut, switch, if, wait, form, formTrigger,
#                 manualTrigger, scheduleTrigger, stopAndError
# @n8n/n8n-nodes-langchain: agent, lmChatAnthropic, lmChatGoogleGemini, outputParserStructured

# --- Python / npm packages --------------------------------------------------
# None required.
